# 00 · 学习路线与文档索引

> 这套文档记录的是「把课程源码手工迁移到自己从零搭建的项目」的完整过程，面向初学者。
> 读完本页，你应该知道：一共有几篇文档、按什么顺序学、每个阶段做完之后怎么验收。

## 1. 这套文档怎么用

建议的阅读顺序不是编号顺序，而是「先跑起来，再拆开看」：

1. 先读本篇，了解全貌和学习路线。
2. 读 `01`，确认环境和目录结构没问题。
3. 读 `02`、`03`，把前端跑通并理解页面是怎么连起来的。
4. 读 `04`，理解后端一次请求是怎么走完的。
5. 读 `05`，把 LangChain 的 Prompt / Model / Parser / LCEL 弄明白。
6. 读 `06`，学会联调排错（这是最容易卡住的地方）。
7. 读 `07`，对照清单逐文件核对，确认没有漏改。

每篇文档都遵循同一个结构：**读完你能做什么 → 正文 → 自测题**。
自测题不要翻答案，先自己画图或口述，说不出来就回读对应小节。

## 2. 三个目录的关系

```
D:\python\llmops\
├── llmops-ui\          本地前端（自己搭建，可随意修改）
├── llmops-api\         本地后端（自己搭建，可随意修改）
│   └── zreadme\        本套学习文档
└── 第3周\第2章 ...\     课程源码（只读参考，不要直接改）
    ├── llmops-ui\      课程前端
    └── llmops-api\     课程后端（含 study\ LangChain 学习脚本）
```

一句话：**课程目录是“答案”，本地目录是“自己写的作业”，zreadme 是“错题本 + 笔记”。**

迁移原则：

- 只迁移本章用得到的东西。课程前端里还有 `HelloWorld.vue`、`components/icons/*`、`__tests__` 等脚手架残留，本章不需要，不要搬。
- 本地版本更新（Tailwind v4、ESLint 10、pnpm 12、Python 3.14），不能照抄课程配置，遇到差异以本地实际运行为准。
- 每迁完一个阶段就提交一次，提交信息遵循 Conventional Commits（见 `02`）。

## 6. 推荐的学习方法

1. **先读一遍，不敲**：通读某篇文档，建立地图，知道有哪些组件、谁调用谁。
2. **再关掉文档手敲**：从空文件开始写，卡住了再回来看。手敲才会暴露“以为懂了”的地方。
3. **每敲完一个阶段就跑一次**：`pnpm dev` 看页面、`curl` 看接口、`pnpm lint` 看规范，不要攒到最后一起调。
4. **每次只提交一个主题**：例如 `feat(chat): 新增聊天页消息渲染`，出问题容易回滚。
5. **把报错原文留在文档里**：`06` 的速查表就是这么来的，下次遇到能秒查。

## 8. 开始之前：三个必须先记住的结论

1. **Arco 组件要用 `app.use` 注册**，忘了不会报错，只会静默不渲染。
2. **Tailwind v4 的入口是 `@import "tailwindcss"`**，引入 v3 的 `@tailwind base` 文件等于没引。
3. **跨域报错不一定真是跨域**：没有 CORS 头的 404/500 也会被浏览器显示为 CORS 错误，先看 Network 的状态码和响应头。
