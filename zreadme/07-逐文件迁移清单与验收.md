## 5. 验收清单（每个阶段跑一次）

### 5.1 前端

```bash
cd D:\python\llmops\llmops-ui
pnpm lint        # ESLint + Stylelint + Prettier 全绿
pnpm build       # vue-tsc 类型检查 + 构建成功
pnpm dev         # 打开 http://localhost:5173
```

页面冒烟测试：

| 路由 | 期望 |
| --- | --- |
| `/` | 自动跳转 `/home` |
| `/home` | 能看到 Arco 按钮，说明组件注册成功 |
| `/space/apps` | 能看到 counter 数字 |
| `/space/apps/<真实uuid>` | 能发消息并收到回复 |
| `/auth/login` | 登录页正常渲染（BlankLayout，无侧边栏） |

### 5.2 后端

```powershell
cd D:\python\llmops\llmops-api
python -m app.http.app        # 必须用 -m，不能直接跑文件
```

```powershell
curl.exe -i -X POST "http://localhost:5000/apps/f670e322-39a2-4e5a-9a7a-9d3732c451bf/debug" `
  -H "Content-Type: application/json" -H "Origin: http://localhost:5173" `
  -d '{\"query\":\"你好\"}'
```

期望：`200`、有 `Access-Control-Allow-Origin`、响应体 `code` 为 `success` 且 `data.content` 非空。

### 5.3 提交链路

```bash
git add <具体文件>
git commit -m "feat(chat): 新增消息渲染"
```

- 故意写一个格式错误的提交信息（如 `update`），应被 commitlint 拦下。
- 故意留一个 ESLint 错误，应被 pre-commit 拦下。

## 6. 已知缺口与待办

| # | 缺口 | 影响 | 建议做法 | 参考 |
| --- | --- | --- | --- | --- |
| 1 | 聊天页没有自动滚动 | 消息变多看不到最新 | 用 `ref` + `nextTick` + `scrollTo({ top: scrollHeight })` | `03`、`06` |
| 2 | `ListView` 无真实应用列表 | 只能手拼 UUID 访问 | 后端补列表接口，前端接 `services` | `03`、`04` |
| 3 | `isLogin()` 固定 `true` | 守卫不生效 | 接入真实登录态（token/localStorage） | `03` |
| 4 | `.env` 缺 `OPENAI_API_KEY` | 换终端启动报 Missing credentials | 补进 `.env` | `05`、`06` |
| 5 | `requirements.txt` 不全 | 新环境装不齐依赖 | 补 `langchain-core`、`langchain-openai`、`flask-cors` | `04` |
| 6 | 后端测试按旧路由编写 | `pytest` 会红 | 按 `/apps/<uuid>/debug` 重写用例 | `04` |
| 7 | `debug()` 未使用 `app_id` | 任意合法 UUID 都能聊 | 后续章节用 `app_id` 查应用配置 | `04` |
| 8 | `handler` 中 `app_id: UUID` 但只 `import uuid` | Python 3.14 惰性注解不报错，低版本会 `NameError` | 补 `from uuid import UUID` | `04` 5.2 |
